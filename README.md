# 休闲游戏之俄罗斯方块

手机优先设计的网页版俄罗斯方块，可直接部署到 GitHub Pages、Nginx 或任意静态网站空间。

## 功能
- 手机触控和滑动手势
- 经典 10×20 棋盘与 7-Bag 随机方块
- 下一个方块预览、幽灵落点
- 分数、等级、消除行数、Combo、Tetris 奖励
- 自动加速难度
- 暂停 / 继续 / 重新开始
- 本地保存最高分
- 音效开关
- PWA，可添加到手机主屏幕
- 离线缓存
- iPhone 安全区域适配

## 操作
- 左右滑：左右移动
- 上滑或轻点棋盘：旋转
- 下滑：软降
- 快速向下滑：直接落底
- 也可使用底部五个按钮

## 部署
这是纯静态项目，无需服务器数据库。将整个目录上传到静态网站即可运行。
